# App Page Video

The file "my movie 1.mp4" should be placed in this directory.

This video will be displayed on the App page (/page-app.php) immediately after the hero section.

## File Details
- **Filename:** my movie 1.mp4
- **Location:** sbd-brutalist/assets/img/
- **Used in:** page-app.php

## Video Requirements
- **Format:** MP4 (H.264 codec recommended)
- **Controls:** The video includes controls for user interaction
- **Autoplay:** Not enabled (user must click play)
- **Dimensions:** Recommend 1920x1080 or appropriate resolution
