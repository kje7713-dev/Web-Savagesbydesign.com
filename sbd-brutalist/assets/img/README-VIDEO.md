# Hero Video Instructions

To enable the hero "sizzle reel" video background:

1. Add your video file as: `hero-sizzle.mp4`
2. Place it in this directory: `/sbd-brutalist/assets/img/`
3. Uncomment the video code in `front-page.php` (lines 9-15)

## Video Requirements

- **Format:** MP4 (H.264 codec recommended)
- **Duration:** 15-60 seconds (looping)
- **Dimensions:** 1920x1080 or higher
- **File size:** Keep under 5MB for optimal performance
- **Content:** High-energy footage showcasing training, movement, or lifestyle

## Alternative: Keep Bold Typography

The current implementation uses a full-screen bold typographic statement. This is equally effective and requires no additional assets. The video is optional.
